# Презентации

Одна папка на презентацию: `ГГГГ-ММ-ДД-тема/`. В ней весь путь от исходных материалов до PDF.

| Файл / папка | Что это | Этап |
|---|---|---|
| `sources/` | Исходники как их прислали: docx, pptx, xlsx, pdf, md, картинки | приём |
| `extracted/` | Извлечённое для анализа: `content.md` (весь текст, таблицы, данные диаграмм, заметки докладчика), `inventory.json`, `tables/*.csv`, `media/`, `pages/*.png` | приём |
| `brief.md` | Бриф: цель, аудитория, главная мысль, факты со ссылками на источник, пробелы | анализ |
| `questions.md` | Уточняющие вопросы, допущения и ответы | вопросы |
| `plan.md` | Сюжет и план по слайдам: макет ДС, заголовок-вывод, данные | план |
| `deck.jsx` | Слайды из макетов дизайн-системы | черновик → правки |
| `index.html`, `<тема>.pdf` | Просмотр в браузере и готовый PDF | черновик → готово |
| `meta.json` | Название, текущий этап и история этапов, версия ДС | все |
| `lib/`, `fonts/` | Копия дизайн-системы версии первой сборки | черновик |

**Этапы:** приём → анализ → вопросы → план → черновик → правки → готово.

## Команды (из корня репозитория)
```
node tools/deck.mjs intake hr-itogi итоги.docx старая.pptx найм.xlsx --title "Итоги HR 2026"
node tools/deck.mjs list                               # все презентации: этап и версия ДС
node tools/deck.mjs stage presentations/<папка> planned --note "план согласован"
node tools/deck.mjs build presentations/<папка>        # HTML + PDF
node tools/deck.mjs build presentations/<папка> --upgrade   # перейти на текущую версию ДС
node tools/deck.mjs new otchet-q3 --from 03            # без исходников, сразу из шаблона
```
Шаблоны для `--from`: 01 базовый, 02 о компании, 03 отчёт, 04 стратегия, 05 статус проекта, 06 КП, 07 продукт, 08 техрешение, 09 кейс, 10 для руководства, 11 онбординг, 12 обучение.

Обычно команды запускает Claude: достаточно прислать файлы в чат и сказать, что это за презентация.
