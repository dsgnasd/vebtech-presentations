# Иконки

81 иконка Lucide (лицензия ISC, lucide-static 1.48.0): линейные, 24×24, контур 2px, `stroke="currentColor"`.

Через `<img>` SVG не наследует цвет и выводится чёрным, поэтому в слайдах используйте компонент `Icon` с тем же именем: он красит иконку токеном (`brand-strong` по умолчанию в подложках, `on-brand` на синем). Файлы нужны для PowerPoint, Figma и других инструментов: вставьте SVG и перекрасьте контур в #1F5FE0 (`brand-strong`) или #161F32 (`ink`).

Недостающие иконки берите на lucide.dev с теми же параметрами.
