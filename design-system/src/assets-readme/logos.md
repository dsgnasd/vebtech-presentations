# Логотипы

Фирменные файлы «ВЭБ Технологии», без изменений.

- `vebtech-logo.svg` — основной: знак `brand` (#3C79FF в файле) и надпись `ink` (#161F32). Для светлых фонов `surface`, `brand-50`, `brand-100`.
- `vebtech-logo-on-dark.svg` — белый (знак с вырезом и надпись). Для тёмных фото с подложкой и небольших синих элементов.

В слайдах логотип выводит компонент `Logo` (варианты `color`, `white`, `mark`, `mark-white`). Правила: высота не меньше 32px, охранное поле — половина высоты знака, без перекраски и эффектов.
