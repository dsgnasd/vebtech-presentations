## Порядок выбора
Для каждого слайда до написания кода ответьте на вопросы по порядку и остановитесь на первом «да»:

1. Есть два и больше сравнимых числа? → **график**.
2. Есть одно-три важных числа? → **крупные цифры**, рядом график, шкала или схема.
3. Есть порядок, время, этапы? → **процесс, таймлайн, дорожная карта**.
4. Есть связи, части целого, уровни, роли? → **структура**: пирамида, слои, оргструктура, своя схема.
5. Есть выбор или сравнение? → **матрица, сравнение, «было — стало»**.
6. Есть предмет или экран? → **фото, скриншот с подписями**.
7. Ни одного «да» → **карточки с иконками** (IconFeature), до четырёх, по 12 слов. Список — только для требований и формулировок, которые нельзя сократить.

## Данные → график
| Что в материале | Форма | Слайд |
|---|---|---|
| Значения по годам, кварталам, месяцам | LineChart, BarChart (до 8 периодов), AreaChart | ChartSlide |
| Категории с величинами | BarChart (`horizontal` при длинных названиях) | ChartSlide, GridSlide |
| Доли целого | DonutChart (2–6 частей), StackedBar `percent`, BreakdownBar | ChartSlide, GridSlide |
| Состав итога по периодам | StackedBar, AreaChart `stacked` | ChartSlide |
| Из чего сложилось изменение | Waterfall | ChartSlide |
| План и факт | PlanFactCard, MeterList, ComboChart | DashboardSlide |
| Доли выполнения, готовность, загрузка | MeterList, ProgressBar | GridSlide |
| Отсев по этапам, конверсия | Funnel | ProcessSlide, GridSlide |
| Было X, стало Y | BarChart из двух столбцов + KpiCard с разницей | GridSlide `feature-left` |
| Диапазоны и оценки | MeterList или BarChart `horizontal` с подписью диапазона | GridSlide |
| Таблица до 8 строк, где важна одна колонка | BarChart `horizontal` вместо таблицы | ChartSlide |
| Таблица, где важны все колонки | DataTable + график главной колонки или Sparkline в строке | GridSlide |

## Смысл текста → схема
| Слова в материале | Форма |
|---|---|
| сначала, затем, этап, шаг, порядок, как работает | ProcessFlow |
| ежемесячно, повторяется, обратная связь, цикл | Cycle |
| даты, история, хронология, вехи | Timeline, VerticalTimeline |
| план работ, кварталы, направления, параллельно | Roadmap, PhaseTimeline |
| уровни, основа, стек, архитектура, слои | Pyramid (`variant="layers"`), своя схема |
| приоритеты, влияние и вероятность, ценность и сложность, риски | Matrix2x2 |
| роли, подчинение, команда | OrgChart, TeamSlide |
| варианты, тарифы, конкуренты, за и против | ComparisonSlide, ComparisonTable |
| проблема и решение, до и после | ComparisonSlide, своя схема «было → стало» |
| система, интеграции, потоки данных, участники | своя схема: узлы и стрелки |
| состояние задач, светофор | StatusTable, Checklist |
| принципы, преимущества, направления | IconFeature 3–4, Cycle или Pyramid, если есть связь |
| экран, продукт, интерфейс | ImageTextSlide, скриншот с выносками |

## Как собрать слайд
- **Визуал занимает больше половины рабочей области**, текст — меньше. Текста рядом с визуалом до 30 слов.
- **Заголовок — вывод**, визуал его доказывает. Главное значение выделено: `highlight`, KpiCard `variant="brand"`, Callout.
- **Комбинируйте** через GridSlide: график + KpiCard + вывод; схема + MeterList; таймлайн + цифры. Сетки — `feature-left`, `top-3`, `bottom-3`.
- **KpiCard — с контекстом:** `delta`, `trend`, Sparkline в `note`, рядом график. Ряд одних карточек с цифрами — не больше одного слайда на колоду.
- **Card — рамка для визуала.** Карточка, внутри которой только Text или BulletList, — это список: ищите форму заново.
- Готовый код всех форм — `design-system/cookbook.md`: скопировать и подставить данные.

## Своя схема
Если формы в ДС нет, нарисуйте её в `deck.jsx`: SVG или блоки внутри `Slide` / `GridSlide`. Корень — с атрибутом `data-visual="название"`.

```jsx
const Node = ({ x, y, w = 300, ht = 120, title, main }) => (
  <g transform={`translate(${x} ${y})`}>
    <rect width={w} height={ht} rx="20" fill={main ? 'var(--brand-strong)' : 'var(--brand-50)'} stroke={main ? 'none' : 'var(--brand-200)'} strokeWidth="2" />
    <text x={w / 2} y={ht / 2 + 10} textAnchor="middle" fontSize="28" fontWeight="700" fill={main ? 'var(--on-brand)' : 'var(--ink)'}>{title}</text>
  </g>
);
const Arrow = ({ x1, y1, x2, y2 }) => <line x1={x1} y1={y1} x2={x2} y2={y2} stroke="var(--line-strong)" strokeWidth="3" markerEnd="url(#arr)" />;
const Scheme = () => (
  <svg data-visual="поток данных" width="1728" height="520" viewBox="0 0 1728 520" style={{ fontFamily: 'var(--font-sans)' }}>
    <defs><marker id="arr" viewBox="0 0 10 10" refX="9" refY="5" markerWidth="7" markerHeight="7" orient="auto"><path d="M0 0L10 5L0 10z" fill="var(--line-strong)" /></marker></defs>
    <Arrow x1={360} y1={120} x2={694} y2={240} /><Arrow x1={360} y1={400} x2={694} y2={280} /><Arrow x1={1034} y1={260} x2={1364} y2={260} />
    <Node x={60} y={60} title="Приложение" /><Node x={60} y={340} title="Сайт" />
    <Node x={704} y={190} w={330} ht={140} title="Платформа" main /><Node x={1374} y={200} title="Учёт" />
  </svg>
);
```
Имена `h` и `W` заняты сборкой, свои переменные называйте иначе. В PowerPoint схема станет редактируемой: узел — фигура с текстом внутри, если `rect` и его подписи лежат в одной `<g>` и подписи по центру; без градиентов, масок и повёрнутого текста — с ними схема уйдёт картинкой. Правила те же: токены, текст от 24px, до 9 узлов, стрелки не пересекают подписи, синяя заливка — у одного главного узла.

## Ритм колоды
Проверяется при сборке (`deck.mjs build`), служебные слайды не считаются:
- визуал не меньше чем на половине содержательных слайдов;
- от 6 слайдов — не меньше трёх разных форм;
- два текстовых слайда подряд — нельзя, три одинаковые композиции подряд — тоже;
- три и больше чисел в тексте — вынести в график или цифры;
- больше 70 слов без визуала — в схему или сократить.

## Честность
- Данные графика — только из исходников, со ссылкой в Source. Чисел нет — выбирайте схему, а не график с выдуманными значениями.
- Схема передаёт связи, которые есть в материале. Порядок, зависимость или причинность не добавлять.
- Форма ради формы не нужна: украшение без смысла, график из одного числа, кольцо из 100%. Не нашли форму — скажите об этом в плане.
