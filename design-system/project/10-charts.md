# Графики и диаграммы

Графики — компоненты на чистом SVG. Они выглядят одинаково на экране, в PDF и в печати. Размеры задаются в пикселях холста.

## Выбор формы

| Задача | Компонент |
|---|---|
| Одна главная цифра | KpiCard `size="lg"` — не график |
| Сравнить величины по категориям | BarChart (`horizontal` при длинных подписях или >7 категорий) |
| Динамика во времени | LineChart (1–4 серии), BarChart по периодам (до 8 периодов) |
| Из чего складывается итог | StackedBar, AreaChart `stacked` |
| Структура (доли 100%) | StackedBar `percent`, DonutChart (2–6 частей) |
| Как из A получилось B | Waterfall |
| Факт против плана | ComboChart (одна ось!) |
| Из чего складывается одна сумма | BreakdownBar (2–5 частей, легенда со значениями и итогом) |
| План против факта по показателям | PlanFactCard / MeterList (DashboardSlide) |
| Этапы с отсевом | Funnel |
| Тренд внутри карточки или таблицы | Sparkline |

## Цвет

- Категориальные серии — `chart-1` → `chart-6` строго по порядку, холодная гамма в одном ключе с брендом и акцентом: синий (бренд), бирюзовый (`chart-2` — темнее светлой бирюзы `accent`), тёмно-синий, небесный, индиго, петроль. Все шесть дают ≥3:1 на белом. Соседние по порядку серии различаются светлотой, поэтому у каждой серии обязательны легенда и подписи.
- В точечных диаграммах и малых мультиплах, где рядом могут оказаться любые серии, — не больше 3 серий.
- Серия 1 (`brand`) — главная: наша компания, факт, текущий год. Сравнительная база и «Прочее» — `chart-other`.
- Одна серия по категориям — все столбцы `chart-1`. Чтобы выделить один, используйте `highlight`: он станет светло-бирюзовым `accent`, остальные — `brand-300`. Выделяйте одно значение — то, о котором заголовок слайда. Бирюза светлая (1.9:1 на белом), поэтому у выделенного столбца обязательна подпись значения — она и несёт информацию.
- Каскад: рост — `chart-1`, снижение — нейтральный `chart-other` со знаком «−», итоги — `brand-deep`.
- Величина (тепловая карта) — одна гамма `brand-100` → `brand-900`. Порядок (воронка, уровни) — `brand-400` → `brand-900`.
- Отклонение от нуля — расходящаяся шкала: `chart-diverging-neg` (тёмно-оранжевый) ↔ `chart-diverging-mid` ↔ `chart-diverging-pos` (синий). Пару красный/зелёный не используем.
- Статусные цвета (`success`, `warning`, `danger`, `info`, `neutral`) — только для статусов, не для серий. Янтарный `warning` отличается от оранжевого полюса `chart-diverging-neg` светлотой (ΔE 23).
- План / факт (MeterList, PlanFactCard): план — серая база `chart-other`, факт — `chart-1`, дополнительные строки — `chart-2`…; шкала общая внутри карточки. Процент выполнения — всегда факт / план, оценку даёт статус (цвет + иконка + слово), а не цвет полосы.

## Разметка

- Одна ось Y. Двух осей не бывает: разные единицы — это два графика.
- Столбцы: скругление 8px на конце данных, прямое основание, зазор 2px между сегментами.
- Линии — 4px, маркеры — 6–9px с белой обводкой. План и прогноз — пунктир.
- Подписи значений прямо на метках (`ink`, 700). Оси и категории — `ink-secondary` / `ink-muted`, 24px. Текст не окрашивается в цвет серии.
- Сетка `line` — только когда подписей значений нет. Нулевая линия и оси — `line-strong`.
- Легенда над графиком при 2+ сериях. Одну серию называет заголовок графика.
- Источник — под графиком, `caption` `ink-muted`.

## Размеры на слайде

- ChartSlide с панелью вывода: график ≈1080×480.
- ChartSlide на всю ширину: ≈1720×480.
- Два графика рядом: по 820×480.
