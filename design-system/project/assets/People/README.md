# Фото-примеры сотрудников

Четыре портрета для образцов и черновиков: команда, оргструктура, контакт на финальном слайде. В реальной презентации замените их фото настоящих сотрудников.

| Файл | Имя в примерах | Роль в примерах |
|---|---|---|
| `aleksey-orlov.jpg` | Алексей Орлов | Генеральный директор |
| `maria-kozlova.jpg` | Мария Козлова | Технический директор |
| `ilya-petrov.jpg` | Илья Петров | Коммерческий директор |
| `anna-smirnova.jpg` | Анна Смирнова | Директор по продукту |

В слайдах фото уже встроены в бандл: `Webtech.samplePeople` (имя, роль, фото) и `Webtech.samplePhoto('Мария Козлова')` → передайте в `Avatar src`, `TeamSlide people[].photo`, `OrgChart`, `ContactSlide person.photo`.

Стиль, которому должны соответствовать настоящие фото: портрет по плечи, нейтральный серый фон, чёрно-белое или приглушённое, взгляд в камеру, квадрат от 400px.
