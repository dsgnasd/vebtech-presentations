Оргструктура: руководитель и 2–5 прямых подчинённых, под каждым — список команд.

## Пропсы
`root={ name, role, photo? }`, `children=[{ name, role, photo?, team?: string[] }]`.

## Правила
- Больше двух уровней на слайд не помещаем: детализацию выносите на отдельные слайды по направлениям.
