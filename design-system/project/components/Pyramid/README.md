Пирамида или слои: иерархия (`variant="pyramid"`, вершина — самое важное) или архитектурные уровни (`variant="layers"`, равные полосы).

## Пропсы
`levels=[{ title, text? }]` сверху вниз, `variant`, `width`.

## Правила
- 3–5 уровней. Верхние уровни темнее (`brand-deep` → `brand-50`), на тёмных — белый текст 28px/700.
