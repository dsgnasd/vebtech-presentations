Статус проекта. Регулярный статус-отчёт по проекту: общий статус, светофор по направлениям, вехи, чек-лист этапа, дорожная карта, риски и решения, которые нужны от руководства.

**Слайдов:** 10. **Автономная версия для показа и печати в PDF:** `templates/05-status-proekta.html` в репозитории.

## Как использовать
- Цифры, имена, названия клиентов и контакты в шаблоне — примеры. Замените их своими данными.
- Удаляйте ненужные слайды и добавляйте макеты из раздела «Макеты слайдов». Порядок и номера Deck пересчитает сам.
- Заголовки формулируйте выводами. Один слайд — одна мысль.
