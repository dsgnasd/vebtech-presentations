Техническое решение. Описание архитектуры: требования, уровни архитектуры, интеграции, стек, нефункциональные требования (SLA, безопасность), план миграции, риски.

**Слайдов:** 11. **Автономная версия для показа и печати в PDF:** `templates/08-tehnicheskoe-reshenie.html` в репозитории.

## Как использовать
- Цифры, имена, названия клиентов и контакты в шаблоне — примеры. Замените их своими данными.
- Удаляйте ненужные слайды и добавляйте макеты из раздела «Макеты слайдов». Порядок и номера Deck пересчитает сам.
- Заголовки формулируйте выводами. Один слайд — одна мысль.
