Отчёт о результатах. Квартальный или годовой отчёт: главные цифры, динамика выручки, план/факт, структура, мост EBITDA, таблица, выводы и планы.

**Слайдов:** 10. **Автономная версия для показа и печати в PDF:** `templates/03-otchet-o-rezultatah.html` в репозитории.

## Как использовать
- Цифры, имена, названия клиентов и контакты в шаблоне — примеры. Замените их своими данными.
- Удаляйте ненужные слайды и добавляйте макеты из раздела «Макеты слайдов». Порядок и номера Deck пересчитает сам.
- Заголовки формулируйте выводами. Один слайд — одна мысль.
