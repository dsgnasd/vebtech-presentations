Дорожная карта / диаграмма Ганта: дорожки (направления) × периоды (кварталы, месяцы). Отметка «Сегодня» — пунктир `accent` с плашкой `accent` и текстом `on-accent` (не `danger`: время — не ошибка; светлая бирюза со статусом не путается).

## Пропсы
- `periods`: подписи периодов (`['Q1 2026', 'Q2 2026', …]`).
- `lanes`: `[{ name, items: [{ start, end, label, status }] }]`. `start` и `end` — в долях периодов от 0 до `periods.length` (0.5 — середина первого периода).
- `status`: `done` (`brand-strong`, галочка), `progress` (`brand-200`), `planned` (контур), `risk` (янтарный `warning`, текст `ink`).
- `today` — позиция отметки «Сегодня» в тех же единицах.

## Правила
- 3–6 дорожек, 4–8 периодов. Подпись полосы — 1–3 слова, она не должна обрезаться.
- Легенду статусов показывает RoadmapSlide.
