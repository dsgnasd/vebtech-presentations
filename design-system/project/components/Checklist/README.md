Чек-лист со статусом каждого пункта: итоги этапа, готовность к запуску, план действий.

## Статусы пункта (`status`)
`done` (галочка `success`), `progress` (песочные часы `info-strong`), `todo` (часы `neutral`, «не начато»), `blocked` (крестик `danger`). Статус — это иконка; смысл дублируйте в тексте или `meta` (срок, ответственный).

## Пункты
`{ text, note, meta, status }`. `note` — пояснение под пунктом, `meta` — справа (дата, владелец).

## Правила
- До 7 пунктов на слайд. Сначала выполненные, затем в работе, затем план.
