Помесячная шкала длинного процесса: месяцы окрашены по состоянию (работа / ожидание), события с датами сверху, именованные этапы снизу. Для истории сделки, presale, проекта длиной 6–36 месяцев.

## Пропсы
- `start`, `end` — первый и последний месяц (`'2024-08'`, `'2026-06'`). Годы подписываются над январём, граница года — тёмная черта.
- `spans=[{ from, to, tone }]` — состояние месяцев: `work` (по умолчанию, `brand-100`) или `waiting` (штриховка — пауза, ожидание решения). Состояние читается и без цвета — по штриховке.
- `milestones=[{ date: 'ГГГГ-ММ-ДД', label, tone?, dateLabel? }]` — события: точка на шкале, выноска, дата `ДД.ММ` и подпись до 2 строк. Два близких одинаковых события объединяйте: `dateLabel: '07.05 и 22.05'`. `tone="accent"` — ключевое событие (крупная бирюзовая точка с обводкой), одно на шкалу.
- `phases=[{ start, end, label }]` — этапы: полоса под шкалой и подпись «Этап · ДД.ММ–ДД.ММ».
- `legend` — свой список `[{ tone, label }]` или `false`. `width` (1728), `labelWidth` (260), `title` (для скринридера).

## Правила
- Подписи раскладываются по рядам автоматически, без наложений. Больше 8 событий — оставьте ключевые, остальное — в хронологию (Timeline, VerticalTimeline) на следующем слайде.
- Подписи событий — глагол или результат («КП на предпроект», «Подписана спецификация»), до 2 строк.
- Одна шкала на слайд, под ней — вывод (Callout) в `TimelineSlide note`.
