Маркированный или нумерованный список — для равноправных формулировок, у которых нет порядка, чисел и связей. Есть порядок — ProcessFlow, числа — график, связи — схема.

## Варианты маркера (`marker`)
`hex` (по умолчанию), `number` (последовательность шагов), `dot` (нейтральный), `check` (выполнено, преимущества), `cross` (недостатки). Маркер можно задать и у отдельного пункта.

## Пункты
Строка или объект `{ title, text, marker }`. С `title` пункт становится двухстрочным: жирный заголовок + пояснение `ink-secondary`.

## Правила
- 3–6 пунктов, каждый до 2 строк. Больше — разбейте на две колонки (TwoColumnSlide) или на два слайда.
- Пункты начинаются с заглавной, без точки с запятой в конце.
- `size="lead"` — список крупнее (32px), когда пунктов 2–3.
- `size="sm"` — компактный список 24px внутри карточки (Card), с 1.10.0.
- `columns` (1) — пункты в 2–3 колонки внутри карточки или широкой области (с 1.10.0): короткие пункты не растягиваются в одну длинную колонку.
