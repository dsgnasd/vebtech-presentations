Из чего складывается одна сумма: полоса 100% из частей, под ней легенда со значениями и долями, внизу итог. Для «структуры отклонения», «из чего состоит долг», «куда ушёл бюджет».

## Пропсы
`items=[{ label, value, color? }]` (2–5 частей), `total` (по умолчанию сумма частей), `totalLabel` («Итого»; `null` — без итога), `showShare` (доли в %), `format`, `height` полосы (40), `title` (для скринридера).

## Правила
- Части — категории, цвета `chart-1…5` по порядку, крупная часть — первой. Больше 5 частей — сверните в «Прочее» (`chart-other`).
- Подписи и значения — в легенде (цвет + слово), не на полосе: узкие сегменты не вмещают текст 24px.
- Для нескольких сумм рядом используйте StackedBar `orientation="horizontal"`.
