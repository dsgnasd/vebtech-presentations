Матрица 2×2: приоритизация по двум осям (ценность × сложность, влияние × вероятность). Правый верхний квадрант — акцентный (`accent-50`), его элементы (`accent: true`) — бирюзовые шестиугольники.

## Пропсы
`xLabel`, `yLabel`, `quadrants` (4 подписи: левый верхний, правый верхний, левый нижний, правый нижний), `items=[{ label, x, y, accent? }]` — координаты от 0 до 1: вправо — больше по горизонтальной оси, вверх — больше по вертикальной. Подписи углов должны соответствовать осям: правый верхний — высокое по обеим, левый нижний — низкое по обеим. Метки у правого края автоматически подписываются слева от значка.

## Правила
- До 8 элементов, подписи в 1–3 слова.
