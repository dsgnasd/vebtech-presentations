О компании Вэбтех. Представление компании: миссия, история, цифры, направления, клиенты, команда и контакты. Для первых встреч с клиентами, партнёрами, кандидатами.

**Слайдов:** 11. **Автономная версия для показа и печати в PDF:** `templates/02-o-kompanii.html` в репозитории.

## Как использовать
- Цифры, имена, названия клиентов и контакты в шаблоне — примеры. Замените их своими данными.
- Удаляйте ненужные слайды и добавляйте макеты из раздела «Макеты слайдов». Порядок и номера Deck пересчитает сам.
- Заголовки формулируйте выводами. Один слайд — одна мысль.
