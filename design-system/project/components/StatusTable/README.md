Статус-таблица «светофор»: направление, статус (Status), прогресс (ProgressBar), комментарий. Главный слайд статус-отчёта по проекту.

## Пропсы
`rows`: `[{ name, status, statusLabel?, progress?, note }]`, `columns` — заголовки четырёх колонок.

## Правила
- 4–7 строк. Комментарий — одна строка: что происходит и что нужно.
- Порядок строк постоянный от отчёта к отчёту, чтобы динамику было видно.
