Для руководства и совета директоров. Материалы для совета директоров: резюме, финансы, ключевые проекты, риски и вопросы на утверждение. Максимум выводов, минимум деталей.

**Слайдов:** 10. **Автономная версия для показа и печати в PDF:** `templates/10-dlya-rukovodstva.html` в репозитории.

## Как использовать
- Цифры, имена, названия клиентов и контакты в шаблоне — примеры. Замените их своими данными.
- Удаляйте ненужные слайды и добавляйте макеты из раздела «Макеты слайдов». Порядок и номера Deck пересчитает сам.
- Заголовки формулируйте выводами. Один слайд — одна мысль.
