Накопительная диаграмма: из чего складывается итог. `percent` — нормированная на 100% (структура).

## Пропсы
`categories`, `series=[{ name, values }]` (до 5), `orientation`, `percent`, `showValues` (подписи внутри сегментов — белым, только если сегмент достаточно крупный), `showTotals`.

## Правила
- Самую важную серию ставьте первой — она лежит на оси и сравнивается точно.
- Подписи внутри сегментов белые: на `chart-1…3` это ≥3.4:1 при кегле 24px и насыщенности 700 (крупный текст по AA).

## Общие правила графиков
- Заголовок слайда формулирует вывод («Выручка удвоилась за 3 года»), график его доказывает.
- Цвета серий — только `chart-1…6` в фиксированном порядке. Серия 1 (`brand`) — главная: наша компания, факт, текущий период. Больше 6 серий — сверните в «Прочее» (`chart-other`).
- Одна ось Y. Двойных осей не бывает: разные величины — это два графика.
- Подписи и значения — 24px, цветом текста (`ink`, `ink-secondary`, `ink-muted`), а не цветом серии.
- Значения подписываются прямо на метках; сетка — только если подписей нет.
- Ось и нулевая линия — `line-strong`, сетка — `line`. Концы столбцов скруглены на 8px, основание прямое. Между сегментами — зазор 2px.
- Легенда появляется автоматически при 2+ сериях. При печати в ч/б серии различаются по светлоте: палитра проверена на дальтонизм (протанопия, дейтеранопия).
- Числа — в формате ru-BY: 1 250,5. Единицы — в заголовке графика, не у каждого значения.
- У каждой метки есть всплывающая подсказка (`<title>`) для HTML-версии.
