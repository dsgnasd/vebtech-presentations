Базовый корпоративный. Универсальная основа на сквозном примере «итоги года и план»: титул, повестка, разделы, плотные слайды GridSlide (график + KPI + цели, три направления + вывод, клиенты 2×2, портфель проектов, приоритеты + таймлайн, бюджет + решения), график с прогнозом, изображение, цитата, финал. Данные вымышленные — замените своими.

**Слайдов:** 14. **Автономная версия для показа и печати в PDF:** `templates/01-bazovyj-korporativnyj.html` в репозитории.

## Как использовать
- Цифры, имена, названия клиентов и контакты в шаблоне — примеры. Замените их своими данными.
- Удаляйте ненужные слайды и добавляйте макеты из раздела «Макеты слайдов». Порядок и номера Deck пересчитает сам.
- Заголовки формулируйте выводами. Один слайд — одна мысль.
