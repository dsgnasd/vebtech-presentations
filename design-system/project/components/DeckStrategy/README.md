Стратегия и цели. Стратегическая сессия: контекст рынка, видение, приоритеты, цели (OKR), приоритизация инициатив, дорожная карта, ресурсы и решения.

**Слайдов:** 13. **Автономная версия для показа и печати в PDF:** `templates/04-strategiya.html` в репозитории.

## Как использовать
- Цифры, имена, названия клиентов и контакты в шаблоне — примеры. Замените их своими данными.
- Удаляйте ненужные слайды и добавляйте макеты из раздела «Макеты слайдов». Порядок и номера Deck пересчитает сам.
- Заголовки формулируйте выводами. Один слайд — одна мысль.
