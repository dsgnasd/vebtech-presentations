Коммерческое предложение. Продажа решения клиенту: задача клиента, решение, выгоды в цифрах, как работаем, кейс, варианты и цены, команда, следующие шаги.

**Слайдов:** 12. **Автономная версия для показа и печати в PDF:** `templates/06-kommercheskoe-predlozhenie.html` в репозитории.

## Как использовать
- Цифры, имена, названия клиентов и контакты в шаблоне — примеры. Замените их своими данными.
- Удаляйте ненужные слайды и добавляйте макеты из раздела «Макеты слайдов». Порядок и номера Deck пересчитает сам.
- Заголовки формулируйте выводами. Один слайд — одна мысль.
