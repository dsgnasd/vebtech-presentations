Продуктовая презентация. Презентация продукта: проблема, продукт, функции, сценарии, интерфейс, метрики, сравнение с альтернативами, дорожная карта продукта.

**Слайдов:** 11. **Автономная версия для показа и печати в PDF:** `templates/07-produktovaya.html` в репозитории.

## Как использовать
- Цифры, имена, названия клиентов и контакты в шаблоне — примеры. Замените их своими данными.
- Удаляйте ненужные слайды и добавляйте макеты из раздела «Макеты слайдов». Порядок и номера Deck пересчитает сам.
- Заголовки формулируйте выводами. Один слайд — одна мысль.
