Процесс из 3–5 шагов слева направо: номер, иконка, заголовок, пояснение, стрелки между шагами.

## Пропсы
`steps=[{ title, text?, icon? }]`, `numbered` (true).

## Правила
- Заголовок шага — глагол или отглагольное существительное: «Аудит», «Проектирование».
- Больше 5 шагов — разбейте на этапы или используйте Timeline.
