Воронка: этапы с убывающим количеством и конверсией между этапами. Цвета — порядковая шкала одного синего тона от `brand-400` к `brand-900`: порядок этапов читается по светлоте.

## Пропсы
`stages=[{ label, value }]` (3–6), `format`, `showConversion`.

## Правила
- Конверсия справа — доля от предыдущего этапа.
- Значение подписано внутри полосы: на светлом первом этапе — `ink`, на остальных — белым 32px/800.
