## Правила
- Цвет — не единственный носитель смысла. Статус = цвет + иконка + слово, серии графиков — цвет + легенда + подписи, сравнение — иконка с текстовой альтернативой.
- Серии графиков различаются светлотой и всегда подписаны (легенда + значения). Пары красный/зелёный нет: рост/падение — `success`/`danger` с иконками тренда, отклонения — синий/оранжевый.
- Акцент не путается со статусами. OKLab ΔE×100 (обычное зрение / худшее из протанопии и дейтеранопии), порог 15 / 10: `accent` против `success` — 19.4 / 18.9, против `warning` — 22.9 / 16.9, против `danger` — 38.8 / 18.8; `warning` против `chart-diverging-neg` — 22.9 / 22.1. Пара `success`/`danger` при дальтонизме неразличима (ΔE 0.2), поэтому статус всегда = цвет + иконка + слово. Светлая бирюза не несёт смысл одна: у плашки есть слово, у столбца — подпись значения.
- Минимальный кегль — 24px. Основной текст — 28px с интерлиньяжем 1.43.
- У графиков есть `title` (описание для скринридера), у каждой метки — подсказка со значением.
- У смысловых иконок есть `title`, у декоративных — `aria-hidden`.
- Порядок чтения совпадает с визуальным: заголовок → контент → вывод → источник.
- В HTML-версии кольцо фокуса — 3px `focus` (`brand-strong`, 5.6:1).
