# Проверка дизайна презентации

Цель: пользователь не видит ни одного сломанного слайда. Автопроверка ловит геометрию, осмотр — смысл и вид. Нужны оба.

## 1. Собрать и исправить ошибки
1. `node tools/deck.mjs build <папка>` — в `check/` появятся снимки `slide-NN.png`, `report.md` и `review.md`.
2. Исправить **все** ✗ в `deck.jsx`, собрать снова. Повторять до нуля. Чинить причину, а не прятать симптом:

| Замечание | Как исправить |
|---|---|
| отступ под заголовком, нижнее поле, карточка, футер | сократить текст, убрать примечание, разделить на два слайда, взять другой макет; отступы ДС не ужимать |
| разные подложки, разная высота, строки колонок | ComparisonSlide или одинаковые Card в GridSlide; пункты парами, одинаковой длины |
| линейки, кегль вне шкалы, обход ДС | выбросить самодельный блок, собрать из компонентов (`design-system/cookbook.md`) |
| нет иконки | имя из `design-system/src/icons.json` |
| наложение | меньше подписей, крупнее график, другая форма |
| одно слово на строке, висячий предлог | переформулировать или неразрывный пробел |
| пустой слайд | укрупнить визуал, добавить данные из материалов или объединить с соседним |

## 2. Осмотреть каждый слайд
Открыть **каждый** `check/slide-NN.png` инструментом просмотра изображений, по одному. Не по коду и не по памяти. Вопросы:

1. **Мысль за 3 секунды.** Заголовок — вывод? Визуал доказывает именно его?
2. **Форма.** Это график, схема, шкала, сравнение — или текст, расставленный по блокам? Текст в рамках → переделать по `design-system/src/docs/70-visuals.md`.
3. **Равновесие.** Колонки устроены одинаково, строки на одной линии, нет полупустой половины и висящего в углу блока.
4. **Воздух.** Между заголовком, содержанием и источником видимые отступы; ничего не прилипло и не упёрлось в край.
5. **Акцент.** Выделено одно главное. Цвета серий осмысленны: одна серия — один цвет, база серая.
6. **Чтение.** Нет мелкой серой массы; под визуалом не больше одной строки примечания и источник.
7. **Целостность.** Иконки на месте, подписи не обрезаны, единицы и даты есть, числа совпадают с источником.

Любое «нет» → вердикт `исправить`, правка, сборка, осмотр заново. Две попытки починить слайд не помогли → сменить макет.

## 3. Заполнить лист
В `check/review.md` у каждого слайда: вердикт `ок` и «что видно» — конкретно про этот слайд, от 30 знаков, без одинаковых фраз. Пример: «Столбцы 43 и 87 дней доказывают рост вдвое, 2026 выделен, источник отделён». Код снимка не менять. Изменённый слайд сбрасывает свою строку.

## 4. Сравнить колоду целиком
Соседние слайды разной композиции, один и тот же смысл не повторён, термины и единицы одинаковы, нумерация и футер на месте.

## 5. Выдать
`node tools/deck.mjs stage <папка> review` → показать PDF. PPTX — `node tools/html2pptx.mjs <папка>` (для внешнего получателя `--safe-font`). Команды откажут, если есть ✗ или пустые строки листа. В ответе одной строкой: сколько слайдов осмотрено, что исправлено, какие предупреждения оставлены и почему.

Нет инструмента просмотра изображений — не заполнять лист: сказать об этом, исправить ✗ и показать пользователю PDF как черновик.

Запрещено: править `meta.json`, `report.md`, коды снимков и файлы проверки, заполнять лист не глядя, выдавать `--draft` за готовое.
